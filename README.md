# NEW CAR CARE — Customer & Workshop Management Website

Premium full-stack starter website for New Car Care.

## Included
- New customer registration and existing customer login
- Customer dashboard:
  - total services
  - last service date
  - total service visits
  - first joined date
  - service history
  - vehicle details
- Workshop admin dashboard:
  - customer list
  - customer details
  - service history
  - contact information captured at registration
  - add service record
- SQLite database
- Password hashing with bcrypt
- JWT authentication
- Responsive premium dark workshop UI

## Run
1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000

Default demo admin:
- Email: admin@newcarcare.local
- Password: ChangeMe123!

Change the admin password before real deployment.

## Important
This is a working starter. For a real public launch, add HTTPS, production secrets, backups, stronger validation/rate limiting, and deploy the server/database securely.

## Scope
PUC, insurance and insurance-expiry tracking are intentionally NOT included, as requested.

## Workshop features
Multiple vehicles per customer, job cards, estimates, service status, payment status, customer search, workshop statistics, inventory, service reminders, feedback, bill numbers, KM tracking and production-ready backup/staff-account structure.
PUC, insurance and insurance-expiry tracking are not included.
